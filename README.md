
# LeetCode 🚀

### A Move Toward DSA

This repository is where I document my journey of learning **Data Structures and Algorithms (DSA)** through LeetCode.

I'm starting this journey to improve my problem-solving skills, understand how different data structures and algorithms work, and become better at writing efficient code. I know that DSA takes time and practice to understand, so I'm trying to learn step by step and stay consistent along the way.

Here, I'll be uploading the solutions to the problems I solve on LeetCode. Some problems might be easy to figure out, while others might take more time and a few attempts. I see both as part of the learning process.

## 🎯 Why This Repository?

The main reason for creating this repository is to keep track of my progress and have a place where I can look back at what I've learned.

My goals are to:

- Improve my logical thinking and problem-solving abilities.
- Build a strong foundation in DSA.
- Learn to write clean, readable, and efficient code.
- Understand the time and space complexity of different solutions.
- Explore different approaches to solving a problem.
- Stay consistent and keep improving with practice.

## 📚 Topics I'm Practicing

As I continue learning, I'll be solving problems related to different DSA topics, such as:

- Arrays and Strings
- Linked Lists
- Stacks and Queues
- Hashing
- Searching and Sorting
- Recursion and Backtracking
- Two Pointers and Sliding Window
- Binary Trees and Binary Search Trees
- Heaps and Priority Queues
- Graphs
- Greedy Algorithms
- Dynamic Programming
- Bit Manipulation

I'll keep adding more topics as I learn and explore them.

## 💻 How I Approach Problems

Whenever I pick a new problem, I try to understand the question first instead of jumping straight into the code. Then, I think about possible approaches, write a solution, and try to understand why it works.

I'm also trying to pay attention to time and space complexity so that I can gradually learn how to make my solutions more efficient.

Of course, I won't understand every problem on the first try, and that's completely fine. If I get stuck, I'll take some time to figure things out, learn from the solution, and try to understand the concept behind it.

For me, the goal isn't just to get an *Accepted* submission on LeetCode. It's to actually understand what I'm doing and learn something useful from every problem.

## 📈 My Progress

This repository will grow as I continue practicing. I'll keep adding new solutions and revisiting older problems whenever I feel there's something more I can learn from them.

I know progress in DSA doesn't happen overnight. It takes patience, consistency, and a willingness to learn from mistakes. I'm just trying to get a little better with every problem I solve.

## 🌱 A Small Step at a Time

I'm creating this repository not because I know everything about DSA, but because I'm learning and want to keep a record of that journey.

There will be easy problems, difficult problems, mistakes, and moments when a concept finally makes sense. All of them are part of the process.

**One problem at a time, one concept at a time, and one step closer to becoming a better programmer.**

Thanks for visiting my repository! 😊

*Happy coding!* 💻
